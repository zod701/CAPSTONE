## 한계

- 이 표는 역 식별 정보만 담는다 — 도착 응답은 저장하지 않는다.
- 실시간 API 는 결과가 없을 때 `errorMessage` 없이 빈 `realtimeArrivalList` 를 200 으로 준다. GTX-A 는 9역이 다 매핑되는데도 응답이 빌 수 있다(운행시간·제공 여부) — 장애로 취급하지 않는다.
- 환승역 응답은 페이지 크기에 잘린다(서울역 total=22). `/0/60/` 처럼 넉넉히 요청하고 `total` 과 실제 건수를 비교해 잘림을 로그로 남긴다.
- 보정 6행 중 `verified=no` 3행(능길역 2행·세종대왕릉역)은 역정보 파일 근거만이다 — 1콜로 확인할 일이 남았다.
